Implement the checkEndsMatch() method. It takes a SequencedCollection of characters (provided as single-letter strings). Return true if the first element and the last element are identical. If the collection is empty, return false.

Note: If the collection has only one element, the first and last elements match.


Sample Input:
A B C D A

Sample Output:
true



Memory limit: 256 MB
Time limit: 5 seconds
