Implement the transferBackwards() method. It receives two sequenced collections of strings: a source and a destination.

You must continually extract the last element from the source and insert it as the last element into the destination, until there is exactly one element left in the source. Additionally, if the extracted string has an even number of characters, you must convert it to uppercase before adding it to the destination. Return the destination collection.

Note: If the source initially has 1 or 0 elements, the destination should remain empty.


Sample Input:
One Two Three Four

Sample Output:
[FOUR, Three, Two]



Memory limit: 256 MB
Time limit: 5 seconds
